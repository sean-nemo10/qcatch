# ZzzMemo

**AIを組み込んだ個人向けタスク管理ツール**です。タスクに話しかけて操作し、Googleカレンダーと同期し、その日の記録から英語の練習問題を作ります。稼働中のインスタンスは [zzzmemo.fly.dev](https://zzzmemo.fly.dev) にあります。

技術文書の本体は英語の [README.md](README.md) です。この文書は要点だけをまとめたものですので、詳細はリンク先をご覧ください。

## 何をするものか

Notion のように多機能を目指すのではなく、**速さとAIの統合**に絞った軽い代替です。

- 自然言語でタスクを書くと、AIが分類して予定に入れます
- 会話ですべてを操作できます。「明日15時に打ち合わせを追加」と書けば追加されます
- 日記を書くと、その日の内容からAIが英語の練習問題を作ります
- GoogleカレンダーとGoogleタスクに自動で同期します

FastAPI と素のJavaScriptで作っていて、PWAとしてスマートフォンにも導入できます。

## 主な機能

- **タスク管理** — 状態（Inbox・Todo・長期・完了・ゴミ箱）、優先度、期限（日付選択と「明日」「来週」のような自然言語の両方）、ドラッグでの並べ替え、繰り返しタスク、期限つきのチェックリスト
- **AIとの会話**（Gemini） — 「今日は何をすべきか」で優先順位の助言、「牛乳を買うを追加」で追加、「レポートを完了にして」で完了、「今日の予定は」でカレンダーの表示ができます。実行例は [AI Chat](README.md#ai-chat-powered-by-gemini) の表にあります
- **日記とブログ** — 自動保存と日付の移動、タグつきの記事管理、完了したタスクから話題を出す提案、書いた内容を広げる提案
- **英語学習** — 完了したタスクと日記から練習問題を3問作り、書いた答えをAIが添削します。添削の結果はフラッシュカードとして保存され、SM-2の間隔反復で復習できます。AIとの複数往復の議論にも対応しています
- **Googleカレンダー・タスクとの同期** — 期限のあるタスクを送り、完了したGoogleタスクを取り込みます。背景で30分ごとに自動同期します

## 自分の環境で動かす

Python 3.10以降と、Gemini APIキー（無料枠は1日1,500リクエスト）が必要です。

```bash
pip install -r requirements.txt
export GEMINI_API_KEY="YOUR_KEY_HERE"
python qcatch.py
```

`http://localhost:5000` がブラウザで自動的に開きます。Windows での環境変数の設定方法は [Quick Start](README.md#quick-start-self-hosted) をご覧ください。

タスクの分類に使うAIは3つから選べます。Gemini 2.5 Flash（無料枠あり）、ローカルの Ollama（無料かつオフライン、導入されていれば自動で検出します）、Claude Haiku（有料）です。

## 構成

| 層 | 技術 |
|---|---|
| バックエンド | Python / FastAPI / uvicorn |
| フロントエンド | 素のJavaScript（ESモジュール、フレームワークなし） |
| データベース | SQLite |
| AI | Gemini 2.5 Flash（Function Calling とストリーミング） |
| ホスティング | Fly.io |
| 認証 | セッションcookie と Google OAuth2 |

`core/` にデータモデル・保存と移行・AIの分類・会話・日記とブログの提案・英語学習・Google同期を置き、`web/` に FastAPI のアプリケーションとAPIのルータを置いています。画面は `web/static/` の1枚のHTMLと17個のESモジュールです。ディレクトリの一覧は [Project Structure](README.md#project-structure) にあります。

## つまずきやすい点

- **ポート5000が使用中の場合** — 環境変数 `PORT` を設定してください
- **Google認証のエラー** — GCPコンソールの「APIとサービス」から OAuth 2.0 クライアントIDの `client_secret.json` を取得し、プロジェクトの直下に置いてください
- **GeminiのAPIが429を返す場合** — 無料枠の毎分15リクエストの制限です。課金は発生しませんので、少し待ってから再試行してください
